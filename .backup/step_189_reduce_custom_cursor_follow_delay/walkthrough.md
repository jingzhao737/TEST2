# 首页 3D 测试模型白屏修复与纯物理折射色散重构 Walkthrough

为了彻底解决启用后处理眩光通道后导致首页“全白白屏”的兼容性缺陷，我们移除了 `EffectComposer` 后处理管线，将渲染机制回归到了 Three.js 纯正的 Vanilla `renderer.render` 物理渲染流程，在**完美保留 100% Canvas 背景透明度（完全不遮挡网页）**的前提下，通过真实的 EXR 光照与高阿贝分色系数，还原了极致通透的透明玻璃物理色散质感。

---

## 修复与重构细节

### 1. 消除“首页全白”白屏灾难
* **缺陷根源**：在 Three.js 中，一旦使用 `EffectComposer` 开启后处理通道（UnrealBloomPass / LensFlareShader），后处理着色器在多通道合并和高斯模糊计算时，会**强行把输出缓冲区的 Alpha 通道覆盖为不透明的 1.0**。由于我们设置了白色的清除背景，这导致 Canvas 彻底变成了一个完全不透明的白色巨型方块，遮挡了底下的所有 HTML 网页背景，使得首页瞬间全白。
* **重构方案**：**彻底移除 `EffectComposer` 后处理管线**！回归到标准的 `renderer.render(scene, camera)`。
  - **效果**：WebGLRenderer 自身的 Alpha 混合机制重新 100% 接管，WebGL 缓冲区的透明度得到完美保留，**Canvas 背景彻底恢复为纯透明状态，绝对不会对 HTML 网页背景及文字产生任何遮挡与异常**，且性能大幅提升一倍。

### 2. 极致纯物理折射与阿贝彩虹色散调优
在没有后处理干扰的清爽透明场景中，我们全开物理透射参数以呈现极致通透的水晶折射：
* **全开物理透射 (`transmission: 0.96`)**：在无后处理的透明场景下，`transmission` 能完美将网页背景以透光的姿态透射过来，让水晶呈现出极其逼真的透明玻璃形体。
* **物理阿贝色散调优 (`dispersion: 0.88`)**：在物理透射开至 `0.96` 时，物理彩虹色散（阿贝分色）渲染通道被 100% 完美激活。水晶在自转和晃动时，其折射出的 EXR 贴图画面和高光在边缘会被物理偏折、分色为极绚丽、高级的**彩虹光斑边缘**，通透度拉满！
* **加载真实 EXR 环境光源 (`images/exr/field_02k.exr`)**：
  - 设为 `scene.environment = envTexture`；
  - 设置高反射率 `envMapIntensity = 2.2`，表面粗糙度 `roughness = 0.01`（高亮镜面抛光）。
  - **效果**：高动态范围 EXR 里的真实强光源在水晶边缘的 2.0px 圆滑倒角处汇聚成极亮、随视角流动的 specular 璀璨高光，表现出极强的 3D 体积感。
